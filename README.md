## Projet phare

### [Vela](https://github.com/gowya/vela) — [▶ voir la démo](https://velaconsult.vercel.app/demo)
Outil de suivi patient pour psychologues, sexologues, hypnothérapeutes…
Le problème : des données de santé ultra-sensibles, des praticiens non techniques, zéro tolérance à l'erreur.

- **Design** : brand book, design system sur tokens (Tailwind v4 + shadcn/ui), onboarding praticien
- **Code** : Next.js App Router, TypeScript strict, PostgreSQL sans ORM, migrations versionnées
- **Rigueur** : chaque requête scopée par praticien, tests unitaires + intégration sur vraie base Postgres, CI GitHub Actions sur chaque PR
